# 📄 La Salle Landscaping - Lien Waiver Generator

A Streamlit web application designed to generate standardized Texas Property Code lien waivers (.docx) for La Salle Landscaping and Lawn Care.

## Features
- Generates **Progress Payment** (§ 53.284(b)) and **Final Payment** (§ 53.284(d)) lien waivers.
- Automatically formats document headers with the company logo, address, and officer credentials.
- Supports single or multiple invoice numbers with automatic currency-to-words spelling.
- Exports directly to Word (`.docx`) format ready for execution and notarization.
